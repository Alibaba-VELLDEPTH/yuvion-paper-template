\section{Supplementary Details}\label{app:details}
The appendix uses lettered section headings. Figures, tables, equations,
algorithms, and listings continue their numbering from the main paper, so
every reference remains unambiguous.

\subsection{Extended implementation details}
Record prompts, preprocessing rules, optimizer settings, and decoding details
that are required to reproduce the work. Use descriptive headings instead of
collecting unrelated details into a single paragraph.

\section{Authoring Notes}\label{app:notes}
\begin{enumerate}
  \item Edit \texttt{metadata.tex}, then replace the abstract and section files.
  \item Add figures to \texttt{figures/} and bibliography entries to
    \texttt{references.bib}.
  \item Use automatic cross-references for every numbered object.
  \item Replace all sample links, names, example text, and empty result cells.
  \item Set \verb|\draftfalse| in the metadata when editorial notes should be hidden.
\end{enumerate}
